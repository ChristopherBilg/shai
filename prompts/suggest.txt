## Rules

- Creating zero issues is a valid outcome — do not fabricate suggestions
- One issue per distinct suggestion
- Create at most 2 issues per run — this step runs after every workflow execution, so an
  unbounded number per run would grow the suggestion backlog faster than it can be triaged.
  If you spot more, file only the highest-value ones; the rest will still be observable later.
- Only suggest improvements to shai itself, never to the external repository
- Do not suggest changes based on a single execution — prefer patterns you can reason about generally
- Keep suggestions specific and actionable, not vague observations
- Shell operators (||, &&, |, >, >>) are NOT available inside gh tool arguments
